# 한정민의 두근두근 소개팅 💕 (SumSum)

> **소개팅 애프터 카톡 구원 프로젝트! 가상 대화 시뮬레이션 & AI 멘트 추천 웹앱**  
> 🌐 **라이브 웹사이트**: [https://qkrxodbs1.github.io/sumsum/](https://qkrxodbs1.github.io/sumsum/)

소개팅이 끝난 후 상대방에게 어떻게 카톡을 보내야 할지 막막해하는 친구 **한정민**을 위해 만든 실전 연애 코칭 & 가상 대화 시뮬레이터 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

### 1. 🔮 상대방 카톡 멘트 분석 & 5대 추천 답변기
- **원클릭 단골 멘트 12종**: 귀가 인사, 음식 취향, 주말 일정 탐색, 늦은 답장/야근, 공포의 단답("넵 ㅎㅎ") 등 자주 나오는 멘트 즉시 분석
- **상대방 속마음 번역기**: 🟢 그린라이트 / 🟡 옐로우라이트 / 🟠 단답 경계 신호등 판별 및 행간 심리 분석
- **5가지 맞춤 추천 답변 (원클릭 1초 복사 & 가상 카톡 즉시 전송)**:
  - 💖 **심쿵 & 설렘 직진형**: 설렘 지수를 올려주는 달달한 플러팅
  - ☕ **부담 ZERO 자연스러운 티키타카형**: 대화가 끊기지 않고 물 흐르듯 이어지는 멘트
  - 🎯 **애프터 신청 킬러형**: 자연스럽게 주말 데이트 약속을 성사시키는 멘트
  - 😆 **유머 & 센스 반전형**: 어색함을 깨고 미소 짓게 만드는 재치 있는 멘트
  - 🧊 **여유 & 담백 쿨한형**: 조급해 보이지 않고 여유로운 어른의 매력
- **⚠️ 워스트 답변 경고**: 읽씹과 차단을 부르는 치명적인 실수 사전 방지

### 2. 📱 리얼 카카오톡 스마트폰 모바일 뷰 시뮬레이터
- 실제 카카오톡 UI/UX 완벽 재현 (배터리, 시계, 프로필 아바타, 1 안읽음 표시, 시간 태그 등)
- **실시간 호감도 하트 게이지 (0% ~ 100%)**: 정민이의 답변 선택에 따라 상대방의 리액션과 호감도 점수 실시간 변동
- **100% 달성 시 축하 연출**: 하트 컨페티 폭죽 효과와 팡파레 사운드
- **자유 대화 모드**: 상대방 대사와 정민이 대사를 직접 입력하며 자유롭게 연습 가능

### 3. 🎮 실전 롤플레잉 게임 (5대 시나리오 퀘스트)
- **Chapter 1**: 소개팅 당일 밤 귀가 카톡
- **Chapter 2**: 다음 날 점심 스몰토크 트기
- **Chapter 3**: 주말 취향 및 관심사 탐색전
- **Chapter 4**: 결전의 날! 애프터 데이트 약속 잡기
- **Chapter 5**: 늦은 답장 / 야근 돌발 위기 대처법

### 4. 💡 소개팅 카톡 필승 6계명 & 행운의 포춘 쿠키
- 답장 간격 미러링 법칙, 1톡 1물음표 원칙, 'ㅋㅋ'와 'ㅎㅎ'의 밸런스 등 실전 팁
- 정민이의 솔로 탈출을 응원하는 행운의 연애 포춘 쿠키 🥠

### 5. 🎁 함께 제공되는 유용한 서비스
- [🍕 오늘 뭐 먹지? (food.html)](https://qkrxodbs1.github.io/sumsum/food.html): 메뉴 결정 장애를 해결해 주는 룰렛 & 16강 음식 이상형 월드컵
- [🎲 로또 6/45 번호 추첨기 (tt.html)](https://qkrxodbs1.github.io/sumsum/tt.html): 공식 색상 및 중복 없는 행운 번호 추첨기

## 🛠️ 기술 스택
- **Frontend**: HTML5, CSS3 (Glassmorphism, Flexbox/Grid, Responsive Mobile-first)
- **Interactive Logic**: Vanilla JavaScript (ES6+)
- **Audio**: Web Audio API (외부 오디오 파일 없이 순수 브라우저 신디사이징)
- **Visual FX**: HTML5 Canvas Heart & Confetti Engine
- **CI/CD**: GitHub Actions & GitHub Pages 자동 배포
